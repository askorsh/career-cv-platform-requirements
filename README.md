# career-cv-platform-requirements
Требования к платформе Career CV (AI-интервью и улучшение резюме)

О проекте
Репозиторий содержит полную спецификацию требований к веб-платформе для соискателей. 
Продукт помогает улучшить резюме и подготовиться к собеседованиям с помощью AI-агента (YandexGPT)

Целевая аудитория
- Студенты (поиск стажировки)
- Junior-специалисты
- Middle-специалисты при смене профессии

Ключевая функциональность:
- Загрузка резюме (PDF) и автоматический парсинг
- Интервью с AI-агентом (5+ вопросов)
- Генерация улучшенного раздела "О себе" и ключевых компетенций
- Тренировка интервью с обратной связью
- Личный кабинет с историей сессий
- Скачивание результата в PDF

 Моя роль: Системный аналитик
Я разработала полный пакет документации с нуля:
-  Анализ бизнес-потребностей и целевой аудитории
-  15+ детализированных Use Cases (основные, альтернативные, исключительные потоки)
-  Функциональные и нефункциональные требования (с приоритетами MUST/SHOULD/COULD)
-  Бизнес-цели по SMART и ключевые метрики продукта
-  Требования к безопасности (152-ФЗ, локализация данных)
-  План развития (MVP → v1.0 → v2.0 → v3.0)
